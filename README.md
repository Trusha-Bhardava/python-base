## 🚀 Getting Started

### 1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

During installation on Windows, select **Add Python to PATH** if that option is available.

### 2. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/Trusha-Bhardava/python-base.git
```

### 3. Open the Project Folder

```bash
cd python-base
```

### 4. Check Python Installation

```bash
python --version
```

If your system uses the Python launcher, you can also try:

```bash
py --version
```

### 5. Run a Python Program

To run a Python file, use:

```bash
python filename.py
```

Replace `filename.py` with the name of an existing Python file in the repository.

On Windows, you can also use:

```bash
py filename.py
```
